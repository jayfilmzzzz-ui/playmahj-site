# playmahj.site

The public website of the Play Mahj iPhone app: home, privacy policy, terms, support, and the pages a shared
link shows to someone without the app (they show nothing from the shared post or meet). Static files only, served by GitHub Pages. Generated from the app's own legal documents
(app commit fdc4a5e); do not edit the HTML by hand.

Fonts: Fraunces and Plus Jakarta Sans, SIL Open Font License (see `assets/OFL-*.txt`).
