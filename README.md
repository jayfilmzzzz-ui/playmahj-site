# playmahj.site

The public website of the Play Mahj iPhone app: home, privacy policy, terms, support, and preview pages for shared
public posts and meets. Static files only, served by GitHub Pages. Generated from the app's own legal documents
(app commit f66ea30); do not edit the HTML by hand.

Fonts: Fraunces and Plus Jakarta Sans, SIL Open Font License (see `assets/OFL-*.txt`).
